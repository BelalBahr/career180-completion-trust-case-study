# Career 180 case study: The Completion Trust Problem

Product Manager case study by Belal Bahr.

- `index.html`: the full case study (brief, PRD, diagrams, metrics, validation note)
- `prototype.html`: working prototype, a single file that opens by double-click
- `sample-data.csv`: the 25 sample certificates used by the prototype
- `brief.md`: the original case brief
- `demo-video.mp4`: 2 minute 26 second narrated walkthrough of the prototype (AI voice)
- `demo-video-silent.mp4` and `narration-script.md`: the same video without audio, and the script with timings, for recording your own voice
